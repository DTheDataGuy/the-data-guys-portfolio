# Who Holds the Kill Switch? Interactive AI-Governance Presentation

**Client / organization:** The Data Guys  
**Built by:** Dei'Marlon Scisney · The Data Guys

![Who Holds the Kill Switch? Interactive AI-Governance Presentation](../../../docs/screenshots/kill-switch.png)

## Overview

A 26-slide, editorial-style interactive web presentation on AI acceleration, regulation and emergency-shutdown authority for a business audience, with a separate speaker guide and participant takeaway.

## Tech stack

`HTML5` · `JavaScript` · `CSS3`

## Engineering highlights

- Data-driven slides (`data.js`) rendered by a small presentation engine (`app.js`).
- Scenario and show-of-hands interactions.
- Keeps introduced proposals separate from enacted law.

## Run it

No build step. Serve the folder and open it in a browser:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`speaker-guide.md` has the talk track and sources; `participant-takeaway.md` is the handout.
