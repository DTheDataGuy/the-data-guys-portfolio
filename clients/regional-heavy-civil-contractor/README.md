# Regional Heavy-Civil Contractor (anonymized)

## [Ticket Desk: Trucking Ticket Intake & Review](ticket-desk/)

A ticket-intake, evidence, review and downstream-entry workspace for project engineering. Trucking and material tickets from many vendor layouts are captured, reviewed, approved as versions, and prepared as daily entries for HCSS HeavyJob and Procore.

**Stack:** JavaScript (ES2022), HTML5, CSS3, JSON data contracts, CSV field mapping

## [Month-End Close & Forecast Hub (case study)](close-forecast-hub/)

A single-company month-end workspace connecting EAC/One-Hitter sheets → WIP reconciliation → Costpoint actuals and inception-to-date true-up → management forecast → submission to enterprise reporting, with source-to-project traceability, exceptions, approvals and versions.

**Stack:** React, TypeScript, Excel / Costpoint GL, Power BI, Power Automate
