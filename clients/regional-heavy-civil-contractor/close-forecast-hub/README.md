# Month-End Close & Forecast Hub (case study)

**Client / organization:** Regional heavy-civil contractor (anonymized)  
**Built by:** Dei'Marlon Scisney · The Data Guys

## Overview

A single-company month-end workspace connecting EAC/One-Hitter sheets → WIP reconciliation → Costpoint actuals and inception-to-date true-up → management forecast → submission to enterprise reporting, with source-to-project traceability, exceptions, approvals and versions.

## Tech stack

`React` · `TypeScript` · `Excel / Costpoint GL` · `Power BI` · `Power Automate`

## Engineering highlights

- Close chain designed around the controller's and forecaster's real workflows.
- Inception-to-date (ITD) true-up and exception population checks against the GL.
- Enterprise architecture blueprint and month-end close process map delivered alongside the app.

Case study only. The compiled build embeds client staff contacts and financial figures, so no code is published here.
