# Community Lending Cooperative (anonymized)

## [Co-op Operations, Lending & Impact Platform](operations-lending-impact-platform/)

A unified operations and impact-reporting platform for a community lending co-op. It covers loan servicing and a lending-system migration, programs and impact, events, surveys, fundraising and finance, with role-based views for admins, lending, programs, finance, leadership and board/funders.

**Stack:** TypeScript, React 18, Vite, Express, SQLite, Drizzle ORM + drizzle-zod, Zod, Recharts, Tailwind CSS, shadcn/ui, Multer  
**Run it:** full-stack app with labeled demo data; see the project README for local setup.
