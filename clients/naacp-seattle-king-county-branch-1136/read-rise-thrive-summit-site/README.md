# Read, Rise & Thrive Early Literacy Summit Site

**Client / organization:** Seattle–King County NAACP, Branch 1136  
**Live deployment:** [readrisethrive.pplx.app](https://readrisethrive.pplx.app)  
**Built by:** Dei'Marlon Scisney · The Data Guys

![Read, Rise & Thrive Early Literacy Summit Site](../../../docs/screenshots/read-rise-thrive.png)

## Overview

Public registration and family event guide for a citywide early-literacy summit and block party, with an organizer view.

## Tech stack

`React` · `TypeScript` · `Vite` · `Tailwind CSS`

## Engineering highlights

- Family-facing guide plus organizer registration management.
- Paired with print, media-kit and signage packages.

## Run it

`production-build/` is the compiled bundle as deployed; application source is held privately for the client. To view it locally:

```bash
npx serve production-build
```
