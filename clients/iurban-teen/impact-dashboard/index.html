    About the Data

    Every number here says exactly what it is. That is what makes it hold up in front of a funder.

    Coverage

    How we count

    Registration
    One Eventbrite attendee row. One person can register for several events, so registrations are not the same as unique students.
    Event listing
    A distinct Eventbrite event ID. Some events run under more than one listing.
    Volunteer
    A registration whose event or ticket name includes "volunteer."
    Returning
    The registrant's own answer to the returning-student question. Unanswered rows are shown separately.
    Program family
    Grouping of event names into five families for this walkthrough. Open for council review.
    Small groups
    Any breakdown under 10 is shown as "<10" to protect privacy.

    Labels used on this dashboard

    Measured Counted directly from source exports.
    Self-reported Answers registrants gave on the form.
    Connecting next Source identified; data not yet loaded.

    Privacy: this page contains aggregate totals only. No names, emails, phone numbers, addresses or guardian details are included.

    Data Studio

    Drop in new Eventbrite exports, adjust how events are grouped, and add outcome results. Every change updates the dashboard instantly.

    1. Import Eventbrite exports

    CSV attendee reports. Files are read inside your browser; names, emails and contact details are never stored or sent anywhere. Only totals are kept.

    Private by design

    2. Outcome results

    Enter results as they come in from check-ins, surveys and alumni follow-up. They appear on the Student Journey right away.

    Entered by team

    3. Save & share settings

    Changes apply for this session. Export a settings file before you close the page, then import it next time or send it to a teammate to pick up where you left off.

    4. Program groupings

    Change any event's program family and every chart updates.
