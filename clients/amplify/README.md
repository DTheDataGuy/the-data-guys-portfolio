# AMPLIFY

## [AMPLIFY Community Intelligence Hub](community-intelligence-hub/)

A client/staff hub that routes partner and staff submissions into linked records, a review queue, a live dashboard and Excel exports.

**Stack:** React, TypeScript, Vite, Tailwind CSS  
**Live:** [amplify-swi.pplx.app](https://amplify-swi.pplx.app)

## [AMPLIFY Microsoft Forms + Power Automate + Excel Knowledge Base](microsoft-forms-system/)

The low-code production architecture behind the AMPLIFY hub: Forms as the collection layer, Power Automate for response handling, and a SharePoint-hosted Excel workbook as the operational knowledge base.

**Stack:** Microsoft Forms, Power Automate, SharePoint, Excel
