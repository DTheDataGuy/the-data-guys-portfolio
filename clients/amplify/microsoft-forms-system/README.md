# AMPLIFY Microsoft Forms + Power Automate + Excel Knowledge Base

**Client / organization:** AMPLIFY  
**Built by:** Dei'Marlon Scisney · The Data Guys

## Overview

The low-code production architecture behind the AMPLIFY hub: Forms as the collection layer, Power Automate for response handling, and a SharePoint-hosted Excel workbook as the operational knowledge base.

## Tech stack

`Microsoft Forms` · `Power Automate` · `SharePoint` · `Excel`

## Engineering highlights

- Import-ready form definitions and post-import setup guide.
- Automation plan covering routing, IDs and linking between forms.
