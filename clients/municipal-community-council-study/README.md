# Municipal Community-Council Feasibility Study (anonymized)

## [Community Council Feasibility Survey Platform](community-survey-platform/)

A public survey plus a separate, restricted executive dashboard that informs whether and how a city should form a new community advisory council. Responses and opt-in contact details are stored separately, and no results are exposed to unauthenticated visitors.

**Stack:** TypeScript, React 18, Vite, Express, SQLite, Drizzle ORM, Recharts, Tailwind CSS, shadcn/ui  
**Run it:** full-stack app; see the project README for local setup.
