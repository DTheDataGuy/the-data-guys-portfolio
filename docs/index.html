    05 · How I work

    Four rules every project follows.

    01

    Provenance first

    Every value keeps its source file, sheet and row. Every dashboard figure is recomputed from stored records.

    02

    Never overwrite the source

    Source values stay immutable. Adjustments are overrides with a reason, an author and a history.

    03

    Label the evidence

    Observed data, reported figures, model estimates and plans are shown separately and never blended.

    04

    Prove it reproduces

    Before a system replaces a spreadsheet, it has to match the approved spreadsheet's totals within a stated tolerance.
