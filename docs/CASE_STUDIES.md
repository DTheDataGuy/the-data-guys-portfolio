# Case Studies (no published code)

Some engagements can't be published as code because the compiled application embeds client financial data or staff contact details, or because the work lives in client-owned systems.

## Month-End Close & Forecast Hub (regional heavy-civil contractor)
A month-end close and forecast workspace connecting EAC sheets → WIP reconciliation → Costpoint actuals and ITD true-up → management forecast → enterprise submission, with exceptions, approvals and versions. Stack: React, TypeScript, Excel/Costpoint GL extracts, Power BI. See [`clients/regional-heavy-civil-contractor/close-forecast-hub`](../clients/regional-heavy-civil-contractor/close-forecast-hub/).

## Enterprise Data-Access Readiness
Architecture and governance work for approved, read-only Costpoint/Snowflake access plus a development environment, as the foundation for the Enterprise WIP Command Center's live feeds.

## Workspace Unlocked (The Data Guys Academy)
